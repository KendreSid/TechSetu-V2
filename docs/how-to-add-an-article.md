# नवीन लेख कसा जोडायचा (तुमच्या हाताने)

## 1. नवा लेख: सहा पायऱ्या

1. VS Code मध्ये `TechSetu-v2` फोल्डर उघडा.
2. `src/content/articles/hi/` मध्ये नवी फाईल बनवा. नाव इंग्रजीत, लहान अक्षरांत, मोकळ्या जागेऐवजी `-`, शेवटी `.md`.
   उदा. `ai-in-agriculture.md`. हेच नाव पत्त्याचा भाग होतं: `/articles/ai-in-agriculture/`.
3. `docs/article-template.md` ची नक्कल करून त्यात तुमचा मजकूर भरा (खाली नियम पाहा).
4. `npm run dev` चालवा आणि `http://localhost:4321` वर तपासा: कार्ड दिसतं का, पान उघडतं का.
5. VS Code मधून Commit आणि Sync (किंवा `git add .`, `git commit -m "Add <लेखाचं नाव>"`, `git push`).
6. Cloudflare चा build संपला की `pages.dev` वर पाहा (Ctrl+F5).

## 2. फाईलच्या वरच्या भागाचे नियम

```
---
title: "शीर्षक"                       <- शीर्षकात : असेल तर दोन्ही बाजूला " " हवेतच
description: "छोटं वर्णन"
date: 2026-10-20                       <- नवे लेख वर दिसतात
urlName: english-url-name
draft: false                           <- true = साईटवर दिसत नाही
---
```

## 3. मजकूर लिहिण्याचे (Markdown) नियम

- उप-शीर्षक: `## शीर्षक`
- मुद्दे: प्रत्येक ओळीच्या सुरुवातीला `- ` (वरच्या ओळीनंतर एक रिकामी ओळ सोडा)
- जाड अक्षर: `**जाड**`
- लिंक: `[दिसणारा शब्द](https://पत्ता)`
- आडवी रेषा: `---`

## 4. नियंत्रण कसं ठेवायचं

- **लेख तात्पुरता लपवायचा:** `draft: true` करा आणि push करा.
- **लेख काढायचा:** फाईल delete करा आणि push करा.
- **लेखात बदल:** फाईल बदला आणि push करा. जुनी आवृत्ती Git च्या इतिहासात राहते, चूक झाली तर परत जाता येतं.
- **कोणी काय बदललं:** Git च्या commit नोंदींमध्ये दिसतं.

## 5. लेखाची भाषा

लेख ज्या भाषेत लिहिला आहे त्या भाषेच्या फोल्डरमध्ये ठेवा: हिंदी `hi/`, मराठी `mr/`, English `en/`.
लेख त्याच भाषेत राहतो. साईटची भाषा हि, मरा किंवा EN कुठलीही निवडली असली तरी **सर्व लेख सगळ्या visitors ना दिसतात**.
भाषा बटणं फक्त साईटवरचे शब्द (मेनू, बटणं) बदलतात, लेखांवर त्यांचा काहीच परिणाम होत नाही.
लेखाच्या पानावर भाषा बटणं नसतात, तिथे फक्त Subscribe बटण असतं.

## 6. प्रकाशित करण्यापूर्वी तपासणी यादी

- [ ] `npm run dev` मध्ये लेख कार्डावर दिसतो.
- [ ] लेखाचं पान उघडतं, शीर्षकं आणि मुद्दे नीट दिसतात.
- [ ] लेखातली आकडेवारी आणि नावं स्रोताशी पडताळली.
- [ ] `draft: false` आहे.
- [ ] शीर्षकात `:` असेल तर " " आहेत.

## 7. काही चुकलं तर

Cloudflare चा build फसला किंवा `npm run dev` मध्ये लाल मजकूर आला तर बहुतेक कारण लेखाच्या वरच्या भागातली चूक असते (अपूर्ण ओळ, " " राहिलेले). आधी वरचा भाग तपासा.
